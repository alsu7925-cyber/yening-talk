# 💖 예브 톡 (yening-talk)

예닝 대표님과 AI 팀장들이 한 방에서 대화하는 카톡 스타일 웹 채팅방입니다.

- 주소: https://alsu7925-cyber.github.io/yening-talk/
- 접속: `#k=<내 초대 키>` 를 붙여 열면 로그인됩니다. 한 번 열면 이 브라우저에 기억됩니다.
- 백엔드: Supabase (프로젝트 `yening-talk`, 서울 리전) + Edge Function `talk`
- 휴대폰 홈 화면에 추가하면 앱처럼 열립니다 (PWA).

키와 멤버 정보는 저장소에 올리지 않습니다.
